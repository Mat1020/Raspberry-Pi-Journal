# Meet Thonny
Thonny is a user-friendly, free, and open-source Integrated Development Environment (IDE) specifically designed for Python programming, particularly for beginners.

## Advantages of Thonny
- A good starting point for beginners
- Comes pre-installed with Raspberry Pi OS
- Includes features like syntax highlighting, breakpoints, and debugger
- Has a beginner-friendly system shell

## To Access Thonny
In order to open Thonny on your Raspberry Pi, you click **Raspberry Pi icon -> Programming -> Thonny.**

## To Create New Projects

1. Create a folder where you're going to put your files. It is highly recommended to make a folder for your projects, then make the folder for the new project. Otherwise, your desk would be supper messy.

2. Open "Thonny" IDE now.

3. After you're done programming, click "Save" button on the top.

4. Save your file in the folder you've previously created for your new project. If you created more than one file, repeat the process to each file.

5. Now, you have your files saved in a folder for your project. You can close Thonny and everything since it's all saved now.

## To Load the Projects

1. Open "Thonny" IDE.

2. Click on "Load" button on the top.

3. Look for the folder name for your project, then click on a file. (Note: it can't open an entire folder, open one file at a time).

4. Now, you're ready to go.
